# Adobe Financial Analysis & Power BI Dashboard

## Project Overview

This project presents a comprehensive financial analysis of **Adobe Inc.**, combining historical financial statement analysis, ratio analysis, forecasting, three-statement financial modelling, and interactive Power BI dashboard development.

The analysis covers Adobe's **Income Statement, Balance Sheet, and Cash Flow Statement**, using historical financial data to evaluate profitability, operating performance, financial position, efficiency, leverage, returns, and cash generation.

## Key Areas Covered

* Performed **horizontal and vertical analysis** of Adobe's financial statements to identify year-over-year changes and changes in financial statement composition.
* Conducted **profitability, efficiency, leverage, return, and cash-flow ratio analysis** to evaluate the company's financial performance.
* Analysed key metrics including **Revenue Growth, Gross Margin, EBITDA Margin, EBIT Margin, Net Profit Margin, ROA, ROE, Asset Turnover, Debt Ratios, Operating Cash Flow Margin, and Free Cash Flow**.
* Built **segment-level revenue forecasts** for Adobe's major business segments, including Digital Media, Digital Experience, and Publishing & Advertising.
* Developed a **three-statement financial model** linking the Income Statement, Balance Sheet, and Cash Flow Statement.
* Created forecast assumptions based on historical trends, percentage-of-revenue relationships, and operating drivers.
* Forecasted major financial statement items including **Revenue, Operating Expenses, Net Income, Assets, Liabilities, Capital Expenditure, Depreciation, and Cash Flow**.
* Built **Power BI dashboards** to visualize financial performance, trends, forecasts, and key financial ratios.
* Designed an interactive dashboard consisting of **Overview, Income Statement, Balance Sheet, Cash Flow, and Major Ratios** sections.
* Used financial analysis to identify key trends in Adobe's **profitability, asset utilization, leverage, returns, and cash generation**.

## Tools Used

**Microsoft Excel** — Financial modelling, financial statement analysis, ratio analysis, forecasting, and three-statement modelling.

**Microsoft Power BI** — Interactive dashboards, KPI visualization, financial trend analysis, and ratio analysis.

## Key Outcome

The project demonstrates an end-to-end financial analysis workflow, progressing from **historical financial statements → financial analysis → ratio analysis → forecasting → three-statement modelling → interactive Power BI visualization**.

It was developed to demonstrate practical skills in **financial analysis, financial modelling, forecasting, Excel, Power BI, and data-driven business interpretation**.
